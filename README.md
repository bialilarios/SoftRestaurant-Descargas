# SoftRestaurant · Descargas

Programas para SoftRestaurant listos para descargar.

## SoftBackup

Respaldos automáticos de SoftRestaurant: ventas por día, catálogos y base de datos completa, en carpetas ordenadas (OneDrive).

**[Descargar la última versión (SoftBackup.zip)](https://github.com/bialilarios/SoftRestaurant-Descargas/releases/latest/download/SoftBackup.zip)**

1. Descomprime el zip y abre `SoftBackup.exe`.
2. Acepta instalarlo en `C:\SoftBackup`.
3. Sigue las pestañas 1 a 5. El `LEEME.txt` incluido tiene los detalles.

Requiere Windows 10/11 (.NET Framework 4.5 o superior, ya viene con Windows). El programa busca solo las actualizaciones publicadas aquí.
